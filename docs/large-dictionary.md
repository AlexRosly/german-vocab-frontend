# Большой словарь

GET /words/mine возвращает доступные карточки с примерами и выбранными переводами примеров. При начальной загрузке frontend не отправляет отдельный запрос /examples для каждого слова. Отдельные запросы остаются для сохранения/редактирования конкретного примера.

Словарь показывает по 30 карточек с кнопкой «Показать ещё 30 карточек». Фильтры, поиск по примерам, счётчики и выбор слов для тренировки работают по всему загруженному словарю, а не только по видимой части. Смена фильтра возвращает показ к первым 30 карточкам. Личные словари, права доступа и прогресс обучения сохраняются.

Для выкладки сначала обновить backend, затем frontend. Миграция БД не требуется.
