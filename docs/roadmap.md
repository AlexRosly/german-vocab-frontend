# Wortkarten — актуальный roadmap

Рабочий план ведётся в backend-репозитории, чтобы статусы не расходились между двумя копиями:

**[Готовые функции, очередь задач и критерии приёмки](https://github.com/AlexRosly/german-vocab-backend/blob/main/docs/roadmap.md)**.

Срез 09.11.2026 сверяет исходное ТЗ, дополнение, решения владельца и актуальный код. В нём раздельно отмечены реализация, частичная готовность и проверка последней версии на Netlify/VPS. Прежние документы project-status и remaining-plan — исторические срезы.

После каждой завершённой функции обновляем соответствующий ID в основном roadmap: что сделано, проверки, commit/push и подтверждение работы на хостинге.

09.11.2026 владелец подтвердил релиз на VPS/Netlify: [рабочий сайт](https://deutsch-wortkarten.netlify.app). Главная и API health проверены (HTTP 200); приёмка полного цикла предложений исправлений отмечена отдельно в R01. Импорт партии из двух книг завершён: [отчёт](https://github.com/AlexRosly/german-vocab-backend/blob/main/docs/books-import-2026-11-09.md).
