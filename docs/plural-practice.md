# Тренировка множественного числа — 20.11.2026

В Словарь → Тренировка добавлен режим «Единственное → множественное». Ученик видит существительное в единственном числе, вводит полную форму, нажимает «Проверить ответ» или Enter. «Не знаю» раскрывает ответ и отмечает слово для повторения. После проверки доступны правильная форма, перевод выбранного языка, заметка и примеры; следующая карточка получает пустое поле и новый результат.

## Слова и проверка

- Только singular с известным der/die/das и полной pluralForm; перевод не требуется. Архив и текущие фильтры сохраняются. Весь выбранный словарь, новые слова, повторения и повтор ошибок используют тот же отбор.
- Формы берутся из карточки. Не генерируем их из окончания и не меняем существующие данные. Пустые значения, суффиксы «-e», «¨-er», маркеры отсутствия формы и пояснения в скобках/с двоеточием исключаются. Тренируемые формы состоят из латинских букв с диакритикой, допустимы слова через пробел и дефис. Другие алфавиты в этом немецком поле не превращаются в ответы.
- Несколько полных вариантов можно хранить через `/`, `,`, `;` или `oder`. Каждая часть должна быть полной; сомнительные записи не разбираются догадкой. Необязательный начальный die удаляется при сравнении и добавляется в показе правильного ответа.
- Unicode NFC, внешние/повторные пробелы и регистр нормализуются. Умлауты и ß различаются: Baume вместо Bäume, Haeuser вместо Häuser и Füsse вместо Füße не принимаются. Никаких нечётких совпадений или автозамен ответа.
- Проверка пустого поля недоступна. После первой проверки результат блокируется; на переходе отправляется KNOWN или NEEDS_REVIEW. Существующая блокировка dashboard защищает переход и сохранение от повторного нажатия. Поле имеет явную метку, подсказку, lang=de, отключённые автокоррекцию/проверку орфографии и объявление результата. После проверки клавиатура освобождается blur; реальный iPhone нового режима отдельно не проверен.

До попытки перевода, pluralForm, заметки и примеров в карточке тренировки нет. Цвет нейтральный. Материалы не скрываются из API: это предотвращение учебной подсказки в интерфейсе, а не защита секрета от DevTools.

## Прогресс и совместимость

Используются существующие API и общий прогресс слова, как у артиклей. Режим и введённый текст отдельно в истории не сохраняются, отдельного SRS для множественного числа нет. Алгоритм/расписание и схема БД не меняются. Длинные занятия сохраняются прежними идемпотентными порциями до 500 ответов. Обратные карточки и артикли сохраняют своё поведение. Интерфейс RU/DE/EN/UK.

## Проверки и выпуск

- 203 клиентских теста: полный существующий набор и шесть новых сценариев отбора/полных альтернатив/Unicode/ошибок/архива/пересечения очередей. Lint и production build.
- Браузерный стенд с вымышленным API: из девяти слов доступны четыре для этого режима; формы-суффиксы, отсутствие множественного числа, уже plural, глагол и архив исключены. В новых/просроченных очередях осталось по два слова. Проверены NFC/нижний регистр/die, ошибка Baume, допустимый второй вариант Worte, «Не знаю», Enter, блокировка ответа, отсутствие подсказок до попытки и сброс следующей карточки.
- Одна завершённая тестовая тренировка отправила ровно четыре ответа, два KNOWN и два NEEDS_REVIEW. Повтор ошибок открыл два ошибочных слова с пустым полем. RU/DE, ширины 320/390 без горизонтального переполнения. Это проверка UI на синтетическом API, не реальной Neon или Safari.
- Проверки выполнены на чистой копии текущего Git frontend с изменениями этой фичи. Незакоммиченные пользовательские изменения globals.css и форматирования dashboard сохранены; в коммит попали только изменения нового режима.

Выпуск только frontend через Netlify Git deploy. Перезапуск backend, новые env и миграции не нужны.
