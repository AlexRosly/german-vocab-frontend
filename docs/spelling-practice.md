# Написание слов — 20.11.2026

В Словарь → Тренировка добавлен режим «Написание слов». Вопрос — выбранный перевод карточки, включая личный перевод; слова без перевода на текущем языке исключены, legacy-русский не подставляется. Нужно написать немецкий текст этой карточки. Пустое поле нельзя проверить. Enter или «Проверить ответ» фиксирует одну попытку, «Не знаю» раскрывает ответ. После проверки поле блокируется и доступны правильное написание, заметки/примеры/множественное число и переход дальше.

## Правила

- Сравнение с German текущей карточки, без автоматического подбора синонимов. Выражения и возвратные глаголы вводятся целиком, с их пунктуацией.
- Пробелы по краям/между словами и Unicode NFC нормализуются. Регистр лексемы, умлауты и ß значимы: Haus правильно, haus неправильно; Bäume и Bäume с составным умлаутом равнозначны, Baume/Baeume неверны; Straße не равно Strasse.
- У существительного с известным артиклем можно опустить der/die/das. Если артикль введён, он должен совпадать с карточкой; регистр самого артикля неважен. Haus / das Haus / Das Haus принимаются, der Haus нет. Для plural используется die. У глаголов и выражений слова der/die/das из начала текста не отбрасываются.
- Старый артикль внутри German существительного не удваивается в проверке/правильном ответе. Написание доверяет данным карточки; ошибка в исходном German исправляется обычной модерацией, а не догадкой проверяющего.
- До попытки на карточке тренировки нет немецкого ответа, озвучки, общей заметки, pluralForm и примеров. Цвет нейтральный. Это учебное скрытие в UI: сами материалы по-прежнему доступны владельцу словаря через API.
- Архив и текущие фильтры исключают слова так же, как раньше; режим доступен для всего выбранного словаря, новых слов, повторения по расписанию и повторения ошибок.

## Прогресс и общий ввод

WrittenAnswer переиспользуется для написания и множественного числа. У каждого режима свой проверяющий: в множественном числе по-прежнему игнорируется регистр и допускаются полные варианты pluralForm, в написании используется точный German. Состояние/блокировка попытки сбрасываются при смене карточки или режима благодаря существующему ключу карточки. Поле имеет явную метку, lang=de, отключённую автокоррекцию/проверку орфографии, ограничение длины и объявление результата; после проверки вызывается blur.

Переход дальше передаёт KNOWN или NEEDS_REVIEW в прежнее сохранение тренировок. Расписание SRS, общий прогресс слова и идемпотентные порции до 500 ответов не меняются. Текст попытки и режим отдельно в историю пока не записываются; это будущий R19. Новых API, миграций, env или зависимостей нет.

## Проверки

209 клиентских тестов (203 прежних и шесть новых), lint и production build на чистой копии Git с изменениями этой фичи. Проверены выбранный/личный перевод без fallback, регистр/артикли, NFC/умлауты/ß, plural/старые префиксы, выражения/глаголы, отсутствие придуманных синонимов, архив и пересечение очередей. Пользовательские изменения globals.css и форматирования dashboard сохранены и не входят в коммит фичи.

Браузер на синтетическом API, без Neon: шесть карточек → четыре подходящие, по две новые/просроченные. До попытки виден только перевод, пустая проверка заблокирована. haus отклонён; Die Bäume и gehen приняты; личный перевод показан как вопрос. «Не знаю», Enter, блокировка после попытки и сброс следующего поля работают. Одна тренировка дала два KNOWN и два NEEDS_REVIEW. Контролируемый первый HTTP503 позволил повторить сохранение с тем же телом/Idempotency-Key, в mock сохранён один результат. Повтор ошибок открыл две карточки. Отдельно проверены Haus без артикля, новые слова и DE-интерфейс; множественное число после переиспользования ввода по-прежнему принимает häuser. Ширины 320/390 без горизонтального переполнения. Это не проверка настоящего iPhone, рабочей Neon или нового выпуска Netlify.

## Выпуск

Только frontend через Netlify Git deploy. Backend/VPS и схема БД не меняются. После сборки владелец проверяет новый режим на нескольких своих карточках и сохранение результата. Оба режима R17 реализованы; публичная приёмка их последних версий остаётся отдельной. Далее по roadmap — трудные слова, дневные ограничения и статистика; почта отложена.
