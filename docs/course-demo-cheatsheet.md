# Wortkarten — шпаргалка к показу 03.11.2026

## Как представить за 20 секунд

«Я разрабатываю Wortkarten — приложение для изучения немецких слов.
Пользователь собирает личный словарь, видит артикли в цвете, добавляет примеры
и переводы и тренируется с интервальным повторением. Прогресс у каждого свой».

## Что показать за 3–5 минут

Перед показом обновить backend, затем frontend на Render и выбрать Deutsch в переключателе
«Язык интерфейса». Язык перевода карточек можно оставить русским или английским.

1. **Вход и личный словарь.** Открыть заранее подготовленный USER; показать
   der Baum, das Haus, die Schule и die Bücher, фильтр урока/уровня и поиск.
2. **Создание.** Добавить одно заранее проверенное слово и пример. Объяснить:
   новая карточка сразу доступна автору и отправляется на проверку.
3. **Библиотека.** Найти опубликованное слово и добавить к себе без копирования.
4. **Переводы.** Показать русский и английский; отсутствие перевода отмечается явно.
   Автор редактирует неопубликованную карточку, администратор — любую.
5. **Тренировка.** Взять 2–3 слова, открыть перевод, нажать «Знаю/Не знаю»,
   показать сохранённый результат и следующую дату в прогрессе. Во вкладке
   «История» открыть последнюю тренировку и показать ответы по словам.
6. **Модерация, если хватает времени.** В отдельном профиле браузера ADMIN
   одобрить новую карточку, затем показать её в библиотеке. При конфликте правок
   карточку нужно перечитать. Не входить в два аккаунта в обычных вкладках одного
   профиля: cookie и события входа между ними общие.

## Как работает внутри

Next.js/React → REST API NestJS → Prisma → PostgreSQL в Neon.
Word — общая карточка, UserWord — связь с личным словарём, WordTranslation —
переводы. WordProgress и StudySession принадлежат пользователю. Пароль хранится
хешем; refresh cookie недоступна JavaScript, access token находится в памяти.

Алгоритм прототипа: «Знаю» → 1, 3, 7, 14, 30 дней; «Не знаю» → 1 день.
Это самооценка ответа, не автоматическая проверка знаний и пока не FSRS.

## Коротко по-немецки

Ich entwickle eine Web-App zum Deutschlernen. Sie heißt Wortkarten.
Jeder Benutzer hat ein eigenes Wörterbuch und einen eigenen Lernfortschritt.
Die Artikel haben feste Farben. Man kann Wörter, Beispiele und Übersetzungen
hinzufügen. Neue Wörter werden vor der Veröffentlichung geprüft.
Beim Lernen wählt man: „Ich weiß es“ oder „Ich muss es wiederholen“.
Die App plant die nächste Wiederholung.
Man kann ein Tagesziel und eine Zeitzone im Konto speichern.
Im Verlauf kann man die gespeicherten Übungen und Antworten ansehen.
Die Oberfläche ist auf Deutsch, Russisch, Englisch und Ukrainisch verfügbar.
Die Sprache der Übersetzungen kann man unabhängig davon wählen.
Als Nächstes möchte ich einen Import und eine Übersicht der Verbformen ergänzen. Das Projekt ist noch in Entwicklung.
