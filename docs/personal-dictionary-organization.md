# Организация личного словаря

Реализация и приёмка 24.11.2026: [единый контракт backend](https://github.com/AlexRosly/german-vocab-backend/blob/main/docs/personal-dictionary-organization.md).

В карточке: «Мои книги, уроки и теги». В настройках: «Нейтральный цвет карточек». Фильтры книги, урока, тега и категории ограничивают также тренировку. Теги, названия уроков и цвет личные; общие источники не редактируются этим действием.

Новый UI совместим со старым API/схемой: capability скрывает новый редактор и цвет, прежние личные книги доступны. Миграция применена к рабочей Neon 24.11.2026 после отдельного согласия владельца; прежние данные сохранены. 24.11 владелец подтвердил появление интерфейса на сайте и принял согласованный этап.

Основной план по-прежнему содержит шесть этапов; подробные R-ID не считаются новыми этапами: [roadmap](roadmap.md).
