# Модерация во frontend

Вкладка «Модерация» доступна в dashboard только при текущей роли ADMIN.
Все запросы идут через общий apiClient; окончательный доступ проверяют AuthGuard,
AdminGuard и ModerationService на backend. Назначения ролей через этот экран нет.

- По умолчанию открыта очередь PENDING_REVIEW. Доступны также PUBLISHED и REJECTED.
- Просмотр GET `/moderation/words/:id` показывает форму слова, все переводы и примеры,
  фиксируя серверную revision. Переводы карточки перечислены с кодами языков;
  язык показа обычных учебных карточек не скрывает материалы от администратора.
- Публикация, отклонение, снятие с публикации и возврат на проверку имеют отдельное
  подтверждение в интерфейсе. PATCH `/:id/status` отправляет только publicationStatus
  и expectedRevision просмотренной карточки. Данные автора, роли и переводы не переписываются.
- После решения обновляются очередь, личный словарь и учебные счётчики. Сохранённый
  результат прошлой тренировки на экране очищается, серверная история остаётся.
- Во время незавершённой тренировки или несохранённых результатов решения недоступны.
  Во время записи нельзя переключать вкладки, фильтр или язык перевода.
- При 409 STALE_REVIEW старое решение блокируется. Нужно нажать «Открыть актуальную
  карточку», перечитать изменения и явно выбрать новое решение. Автоматической публикации
  с новой revision нет. Такое же повторное чтение требуется при неоднозначной сетевой ошибке.
- При DUPLICATE_WORD отображается сообщение сервера и доступен просмотр существующей
  карточки; автоматического объединения или переноса личных связей нет.
- Ошибки очереди/деталей можно повторить отдельно. Запоздалые чтения отменяются и
  не заменяют другой выбранный фильтр или карточку. Изменения не повторяются на 5xx.

Проверки: `npm run test:client`, `npm run lint`, `npm run build`; браузерные сценарии
сначала выполняются на временном mock API. Это не проверка настоящей SQL-изоляции.
Для живой проверки нужен backend с прежней auth-миграцией и отдельно назначенный
аккаунт ADMIN. Код экрана не применяет миграции и не меняет роли в Neon.
