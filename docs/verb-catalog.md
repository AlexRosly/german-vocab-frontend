# Справочник глаголов

Вкладка «Глаголы»: поиск по инфинитиву/Präteritum/Partizip II, выбор всех опубликованных глаголов или личного словаря, фильтр haben/sein и страницы по 30 карточек. Перевод соответствует выбранному языку; личный перевод остаётся личным. Таблица показывает все варианты найденной карточки, включая различия значения и возвратности, и собирает Perfekt теми же функциями, что карточка слова.

Клик по глаголу открывает окно с формами и примерами. В словаре, библиотеке и модерации есть переход «В справочник глаголов», сразу открывающий выбранную карточку. На узком экране таблица превращается в вертикальные записи с подписями. Escape/«Закрыть» снимают блокировку прокрутки и возвращают фокус.

Клиент использует существующий apiFetch/авторизованный apiClient, AbortSignal и проверяет ответы, пары форм, ID, пагинацию. Ошибка загрузки показывает кнопку повторения. Ответ предыдущего поиска не заменяет новый. Входные значения кодируются URLSearchParams, ID ограничен допустимыми символами. Токены не записываются в localStorage.

Вкладка и ссылки доступны только при `/verbs/config` → enabled:true, version:1, catalog:true. На старом backend сохраняется прежний просмотр форм, новый раздел скрыт до обновления VPS. Новых переменных окружения и миграций нет; данные предыдущего импорта сохраняются.

Проверки: 165 клиентских тестов, lint и production build из изолированного снимка без незакоммиченной верстки владельца. Браузерный стенд — только синтетические карточки/mock API: страницы, поиск формы, фильтры, карточка с примерами, Escape/возврат фокуса, переход из словаря, 503→повторение и адаптация на узком экране. Настоящая приёмка на VPS — после ручного обновления backend владельцем.
