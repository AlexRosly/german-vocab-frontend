# Работа над Wortkarten frontend

- Продолжай существующий проект небольшими завершёнными этапами. Общайся с пользователем по-русски.
- Порядок, установленный пользователем: реализовать фичу → выполнить относящиеся к ней проверки → сделать осмысленный коммит → выполнить push в origin текущей рабочей ветки. Для обычных commit/push повторное согласование не требуется; ограничения среды доступа соблюдай.
- Не включай в коммит посторонние черновики, .env, секреты, node_modules или результаты сборки. Сохраняй чужие незакоммиченные изменения.
- Основные проверки: npm run test:client, npm run lint, npm run build. Для изменений UI проверяй рабочие сценарии в браузере; отличай тестовый mock от проверки настоящего API/Neon.
- Сохраняй персональность словаря и прогресса. Используй существующий apiClient, доступ к карточкам и selectedTranslation; не храни access token в localStorage и не подменяй отсутствующий перевод русским.
- Подробности реализованных этапов и подключения API находятся в docs/.
