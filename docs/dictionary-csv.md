# CSV личного словаря

В Настройках добавлена панель «Мои данные: CSV»: экспорт всего доступного личного словаря (включая архив), скачивание пустого шаблона и отдельного примера заполнения. В памятке показаны обязательные поля и правила Excel/CSV. Тексты RU/DE/EN/UK.

Шаблон — 20 основных колонок, пример — существительное Haus, глагол gehen и выражение Guten Tag. Экспорт — 58 колонок, включая word_id, все 11 общих и личных переводов, личную заметку/книги/флаги, все примеры и варианты форм. Дополнительные структуры сохраняются в *_json. История тренировок и общие связи не входят в этот файл. Полный контракт — backend docs/dictionary-csv.md.

Импорт CSV/Excel пока не реализован: нет формы загрузки, предпросмотра или записи. ID и версия подготовлены для дальнейшего безопасного распознавания существующих карточек. Пользовательские общие правки/модерация, неоднозначные совпадения и идемпотентность будут реализованы следующим отдельным этапом; экспорт не меняет БД.

Используется существующий authenticated apiClient. Capability /dictionary-export/config скрывает панель на старом API. Скачиваются только относительные маршруты фиксированных вариантов, проверяются Content-Type/версия/размер/заголовок CSV, filename фиксирован. Отмена/размонтирование/смена аккаунта прекращают скачивание; поздний ответ другого аккаунта не становится файлом. Установлен таймаут 60 секунд. Blob URL освобождаются после запуска загрузки и при уходе со страницы. Публичные токены/credentials не записываются в файл/URL/localStorage.

Проверены 176 клиентских тестов, lint/build рабочей и изолированной сборки без посторонних локальных правок. В браузере с mock API проверены три download-события и реально скачанные файлы (0/3/1 строк), повтор после 503, памятка, 320/390 без горизонтальной прокрутки. Backend отдельно проверен настоящим read-only экспортом словаря владельца. Новая версия на production VPS отдельно ещё не подтверждена.

Для включения обновить backend на VPS обычным порядком git pull/npm ci/build/pm2 restart wortkarten-api; frontend получает Git-релиз Netlify. Новых env-параметров/миграций нет. После обновления: Настройки → Мои данные: CSV.
