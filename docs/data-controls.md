# Данные и аккаунт

[Единый контракт](https://github.com/AlexRosly/german-vocab-backend/blob/main/docs/data-controls.md).

Настройки → «Архивировать аккаунт»; восстановление — отдельный режим формы входа. Настройки ADMIN → «Журнал общих изменений». Публичные /privacy, /terms, /contact доступны без входа. Полное удаление данных остаётся запросом на email; архив не выдаётся за удаление. Адрес для полноценного Impressum пока отложен владельцем.
