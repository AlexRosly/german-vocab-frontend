# Сочетания существительных и глаголов

В словаре, библиотеке и модерации у существительных доступна кнопка «Сочетания с глаголами». Она открывает готовые фразы, выбранный перевод и необязательную грамматическую подсказку. Кнопка «Формы глагола …» ведёт в существующий справочник с Präteritum, Partizip II и Perfekt. В справочнике доступен обратный список «Сочетания с существительными» с открытием существительного.

ADMIN добавляет и изменяет сочетания в модальном редакторе существительного: поиск существующего опубликованного глагола, полная немецкая фраза, необязательные переводы на языки каталога, подсказка по управлению. Выбор глагола ограничен существующими карточками с формами. USER только просматривает; сообщения об ошибках передаются через существующие предложения исправлений общей карточки.

Переводы необязательны, русской подстановки нет. Смена языка внутри редактора сохраняет заполненные поля. Дубликат/конфликт ревизии возвращается с сервера; при ошибке черновик не исчезает. Загрузка сохранённой версии после 409 выполняется только отдельной кнопкой. Удаление требует подтверждения в модальном окне и удаляет только сочетание, не карточки и не прогресс.

В модерации открытый редактор блокирует закрытие/навигацию/решения фоновой карточки. После сохранения карточка модерации перечитывается с новой ревизией. Интерфейс RU/DE/EN/UK. Вложенные диалоги имеют фокус заголовка, Escape и блокировку фоновой прокрутки; поля 16px и кнопки минимум 44px.

`GET /collocations/config` определяет доступность: при старом API 404 или `enabled:false` кнопки скрыты. Для включения нужны backend из этого релиза и миграция `20261116120000_add_word_collocations`; отдельное согласие на production-миграцию запрашивается владельцу. Миграция пока не применена.

Проверено: 171 клиентский тест, lint, сборки рабочей и изолированной версии; браузер с одноразовым mock API, ADMIN/USER, ввод без перевода, сохранение языков, 409/reload, удаление, переходы noun↔verb, блокировки модерации и мобильные ширины 320/390. Работа именно с production проверяется после разрешённой миграции и обновления VPS.
