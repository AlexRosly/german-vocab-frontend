# Моя заметка

У каждой карточки личного словаря появилась кнопка «Моя заметка». Редактор
загружается при первом раскрытии, без отдельного запроса для всех карточек.
Сохранение/очистка — явное действие; состояние загрузки, ошибки и конфликт
переведены на ru/de/en/uk. UI объясняет, что заметка видна только владельцу.
Существующее поле Word.notes переименовано в интерфейсе в общую заметку карточки.
Общие заметки не копируются в личные автоматически и не меняют содержимое.

До 2000 Unicode-символов. Пустой текст после сохранения убирает личную заметку.
HTML выводится текстом, не выполняется; язык UI/перевода не переводит заметку.
Скрытие/раскрытие и смена UI-языка сохраняют черновик. После перезагрузки или
смены вкладки доступна последняя сохранённая серверная версия, не локальный
черновик. Заметки не кладутся в localStorage.

Типизированный клиент использует apiFetch, проверяет wordId, text и revision,
передаёт AbortSignal и не повторяет мутацию после 409/500 автоматически.
Поздний ответ после размонтирования/смены аккаунта не перерисовывает редактор.
409 сохраняет черновик и блокирует перезапись. Явная кнопка загрузки сохранённой
заметки предупреждает скопировать черновик: поле будет заменено свежим текстом.
Ошибка повторного чтения не убирает защиту от конфликта и возможность перечитать.

Заметка доступна только на слове своего активного словаря. Отвязка слова не
уничтожает её: после повторного добавления откроется прежняя заметка. Другой
аккаунт и ADMIN видят только собственную. Личная заметка не входит в общую
карточку, библиотеку, модерацию, тренировки, поиск или редактирование Word.

Проверки: 96 client-тестов, lint, production build; backend words 42,
moderation 38, build. Браузерный localhost mock: сохранение, reload, сохранность
черновика при скрытии/смене UI, буквальный HTML, 500 и повтор, конфликт с черновиком
и явная загрузка актуальной версии, очистка, два разных аккаунта. Retention при
отвязке/возврате проверен backend HTTP-тестом. Это не smoke реального Render/Neon.

Выкладка: миграция в согласованной демо-БД, затем Manual Deploy backend main и
после успешного старта — frontend main. На демо проверить «Моя заметка», reload,
отвязку/возврат и независимость второго аккаунта в другом профиле браузера.
