# Формы глагола

В «Добавить слово» есть отметка «Это глагол». Она открывает обязательные Präteritum / Partizip II / haben или sein, снимает артикль и очищает множественное число. Можно добавить до четырёх вариантов с пояснением значения и отметкой возвратности (`sich`). Формы вводятся для er/sie/es; Perfekt собирается из сохранённой пары, например `ist umgezogen` или `hat sich umgezogen`.

При редактировании формы загружаются вместе с карточкой. Обычная правка перевода/заметки не снимает классификацию. Явное снятие отметки у прежнего глагола отправляет `isVerb:false`. Неизменённые обычные слова не отправляют это поле, чтобы не удалить формы, которые могли появиться после загрузки списка.

Кнопка раскрытия «Формы глагола» находится в карточках словаря, библиотеки и модерации. ADMIN редактирует опубликованную карточку через обычное «Изменить слово», автор — свою неопубликованную. Это общие формы карточки; личные переводы и заметки остаются личными.

Доступность редактора определяется авторизованным `GET /verbs/config`. При старом backend (404) новые поля скрываются и не попадают в запросы. Для включения нужны миграция `20261115120000_add_word_verb_forms` и обновление backend на VPS. Они требуют отдельного согласия владельца рабочей Neon. Деплой frontend может произойти раньше и совместим со старым API.

Следом планируются отдельный справочник глаголов и сочетания с существительными. В текущем этапе они не объявляются готовыми.

Проверки: клиентские тесты, lint и production build; отдельный локальный стенд с mock API, без реальных пользователей/Neon. Проверены обязательность форм, создание, повторное редактирование, оба вспомогательных глагола, `sich`, добавление/удаление варианта и ширина 390 без горизонтального переполнения. Настоящий iPhone/Google-вход/ежедневные тренировки ранее приняты владельцем; повторная приёмка этих сценариев для этого этапа не требовалась.
