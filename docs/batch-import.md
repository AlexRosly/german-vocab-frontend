# Подготовка слов из Excel

02.11.2026. Для наполнения словаря подготовлены Excel-шаблон и локальный CLI в
backend: `templates/wortkarten-words-template.xlsx`, `scripts/import-words.cjs`,
`examples/import-words.example.json`, инструкция `docs/batch-import.md`.

Можно прислать одну колонку немецких слов. При подготовке ассистент дополнит
нужные поля и примеры, уточнит неоднозначные значения и выдаст проверяемый JSON.
Шаблон содержит листы «Слова» и «Примеры»; пользоваться именно им необязательно.

CLI по умолчанию выполняет offline preview. --apply создаёт новые карточки через
существующий API со статусом «На проверке». Пользователь затем публикует их
через модерацию. Дубликаты не переписываются; у каждой строки есть отчёт.
Неопределённый результат сети блокирует слепой повтор. Это не импорт XLSX кнопкой
в браузере и не готовый автоматический переводчик; исходные слова пока не получены.

Проверены 15 тестов импорта и сборка backend; live API/БД не изменялись. Frontend
в этом этапе меняется только документацией. Deploy и миграция для CLI не нужны.
Мобильная вёрстка остаётся отложенной задачей по просьбе владельца.
