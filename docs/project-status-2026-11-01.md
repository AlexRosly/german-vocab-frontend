## Что означает «готово»

«Реализовано» = есть код и относящиеся к нему проверки. Это не равнозначно
«проверено на публичном сервере с настоящей БД». Последние подтверждённые наборы
автоматических проверок до истории: backend 159. На этапе истории прошли
54 study-теста, 37 languages-тестов и все 96 frontend-тестов; сборки
успешны. На этапе активных входов прошли 28 auth-тестов; на этапе личных заметок —
42 words-теста, 38 moderation-тестов и build. Остальные
backend-наборы повторно не запускались. HTTP-тесты backend используют подмену Prisma, браузерные сценарии
проверялись с mock API. На живой ветке «миграцион» теперь применена auth-миграция;
подтверждены чтение сессий и ответы публичного API, регистрацию подтвердил пользователь.
Полный сценарий двух аккаунтов, публикации и обучения на живом демо ещё нужно
проверить отдельно; успешная регистрация не заменяет эти проверки.

## Что изменилось относительно двух документов

1. Состояние «только схема Prisma» в дополнении устарело: уже есть рабочие модули
   авторизации, словаря, обучения, модерации и переводов, включая frontend.
2. Дополнение уточняет более раннее ТЗ: общая Word и связь UserWord вместо
   отдельных копий. Поэтому удаление из личного словаря означает отвязку; архив
   и пользовательские переопределения остаются отдельной задачей.
3. Email/password реализован собственным сервисом с bcrypt и сессиями. Supabase
   в базовом ТЗ был предложением, не поводом переписывать существующую авторизацию.
4. ТЗ описывает FSRS/четыре оценки; дополнение фиксирует двухкнопочный алгоритм
   прототипа. На показе честно называем его упрощённым интервальным повторением.
5. В дополнении упомянут ReadCommitted; текущая запись использует Serializable
   с повтором конфликтов, статистика — RepeatableRead. Возвращать старое значение
   только ради соответствия прежнему тексту не нужно.
6. Наличие колонок языка/провайдера/даты в схеме не означает готовый UI/OAuth/
   подтверждение email. «Языки переводов» и «перевод интерфейса» — разные функции.

## План до вторника

**P0 — закончить проверку демо:** инфраструктура, auth-миграция и ADMIN уже готовы.
Проверить обычный USER и ADMIN в разных браузерных профилях: собственные словари
изолированы, новая карточка видна автору, публикация выводит её в библиотеку,
добавление другим пользователем не копирует Word. Пройти тренировку, перезагрузить
страницу, проверить прогресс и выход. Правка перевода и убирание карточки из
словаря не должны уничтожать историю. Не отмечать весь сценарий выполненным
только по успешной регистрации.

**P0 — подготовка показа:** 8–12 проверенных слов разных артиклей/мн. числа,
два примера, два языка переводов; сценарий на 3–5 минут и один запасной скриншот
или локальный запуск. Не вводить личные пароли при показе, использовать демо-аккаунты.
За 5–10 минут открыть сервисы и пройти вход; Free может просыпаться около минуты.

## Отложенная проверка мобильного интерфейса

По сообщению владельца вход с телефона работает, но мобильную вёрстку нужно
поправить. По его указанию отложено на отдельный этап: проверить основные экраны
на узком viewport и исправить выявленные проблемы. В текущем этапе адаптивная
переработка интерфейса не выполнялась.
