# Wortkarten: сверка ТЗ и план к демонстрации

Дата проверки: 01.11.2026. Демонстрация: вторник, 03.11.2026.
Основа: ТЗ v1.1 от 08.10.2026 и дополнение v1.0 от 30.10.2026,
фактический код backend/frontend. Исходные версии до подготовки размещения:
backend `50d5b8b`, frontend `9b27898`. Документ дополнения описывает состояние
на 30 октября и уже отстаёт от выполненных этапов.

## Что означает «готово»

«Реализовано» = есть код и относящиеся к нему проверки. Это не равнозначно
«проверено на публичном сервере с настоящей БД». Последняя подтверждённая база
автоматических проверок до подготовки размещения: backend 150, frontend 43 теста;
сборки успешны. HTTP-тесты backend используют подмену Prisma, браузерные сценарии
проверялись с mock API. Новая auth-миграция в реальной Neon этой работой не применялась.

## Матрица требований

| Область | Статус | Фактически есть / что остаётся |
| --- | --- | --- |
| Разделённые web/API | Реализовано | Next.js/React/TS и NestJS/Prisma/PostgreSQL, два GitHub-репозитория, REST `/api/v1`, Swagger `/docs`. Монорепозиторий был рекомендацией, перенос не требуется. |
| Email + пароль | Реализовано базово | Регистрация, вход, выход, восстановление сессии, bcrypt, короткий access в памяти, HttpOnly refresh cookie, USER/ADMIN. |
| Полный жизненный цикл аккаунта | Не завершено | Нет подтверждения email, восстановления пароля, выхода из всех сессий, удаления аккаунта, полноценного профиля. Поле emailVerified не означает наличие подтверждения email. |
| Google / Apple / связывание | Не реализовано | Схема Account предусматривает провайдеры, но OAuth-потоков и безопасного связывания в UI/API пока нет. |
| Личный словарь + общая библиотека | Реализовано | Word + UserWord, опубликованная библиотека, добавление без копирования, личная видимость, убирание связи без уничтожения Word/истории. |
| Создание/редактирование карточек | Реализовано | Немецкая форма, артикль/число, русский начальный перевод, мн. форма, заметки, CEFR и номер урока. Автор правит свои неопубликованные, ADMIN — любые. |
| Архив и личные настройки карточки | Не завершено | Отдельного архива нет. «Убрать из словаря» удаляет связь, а не общее слово. Нет избранного, тегов, пользовательского цвета, персональных заметок/переопределений. Сейчас заметки, урок и уровень находятся на общей Word. |
| Цветовая система | Реализована в основных учебных экранах | der — синий, das — зелёный, die ед. — красный, мн. число — оранжевый, без артикля — нейтральный. Нет custom_color, отдельных gender/article_status, полного аудита всех будущих экранов. |
| Переводы слов | Реализовано | WordTranslation ru/de/en/uk, выбор языка показа, редактор автора/ADMIN, отсутствие нужного перевода показано явно, RU синхронизируется с legacy полем. |
| Ограничения переводов | Частично | Одна строка на слово/язык, одна выбранная локаль показа. Новая карточка пока требует начальный русский перевод; несколько значений одного языка отдельной моделью не представлены. |
| Язык интерфейса | Частично | Backend хранит отдельный interfaceLanguage и каталог четырёх языков. Сам интерфейс русский, выбора и UI-словарей ru/de/en/uk ещё нет. |
| Примеры и озвучивание | Реализовано базово | CRUD примеров с правами, Web Speech API для слов/предложений при поддержке браузера. Переводы примеров пока одноязычные; мультиязычной модели и гарантированного голоса нет. |
| Поиск/фильтры | Реализовано базово | Поиск библиотеки через API, личный поиск и фильтры уровня/номера урока/артикля, сортировка, фильтр прогресса. Нет пагинации, поиска по тегам/избранному и завершённой масштабируемой выборки. |
| Уроки | Частично | Номер урока и CEFR, фильтры. Нет сущности Lesson с названием, датой, заметкой и отдельным управлением уроками. |
| Дубликаты | Реализовано базово | Проверка точных совпадений и конфликт при публикации, понятные ошибки; без молчаливого объединения. Нет fuzzy-поиска, интерфейса ручного объединения и переноса связей. |
| Модерация | Реализовано базово | Очередь/фильтры/детали, PENDING_REVIEW/PUBLISHED/REJECTED, подтверждение решения, revision и защита от старого решения, редактирование переводов. |
| Расширенная модерация | Не завершено | Нет причины отказа/NEEDS_CHANGES, журнала решений, истории правок; в UI не выведены автор и даты, требуемые дополнением. |
| Персональная тренировка/SRS | Реализовано базово | Новые слова, due, показ перевода, «Знаю/Не знаю», повтор ошибок, персональный WordProgress, сохранение сессий с Idempotency-Key. |
| Алгоритм | Принятый упрощённый прототип | KNOWN: 1/3/7/14/30 дней; NEEDS_REVIEW: 1 день. Это не FSRS и не оценки Again/Hard/Good/Easy. Не подменять алгоритм перед показом без отдельного решения. |
| Расширенные режимы | Не реализовано | Нет обратного направления, проверки написания/артикля/множественного числа, закреплённого признака «трудное», отдельных overdue-очередей и пользовательских дневных лимитов. |
| Часовой пояс/цель | Не завершено | Часовой пояс пользователя не хранится; сутки статистики считаются на сервере. Видимая цель «10» фиксирована и относится к текущей тренировке, не является сохранённой настройкой дневной активности. |

| Сохранность при переводах/отписке | Реализовано и проверено в тестах | Правки переводов и убирание UserWord не сбрасывают сессии/SRS. Реальные конкурентные SQL-сценарии требуют проверки на демо-БД. |
| Импорт/экспорт | Не реализовано | Нет текста/CSV/XLSX, сопоставления колонок, предпросмотра, отчёта, экспорта личных данных. |
| Глаголы/связанные выражения | Не реализовано | Нет справочника форм, haben/sein, управления, отделяемости, лицензированного источника и модели связей выражений. |

| ИИ | Не реализовано | Нет предложений/подтверждения, адаптера провайдера, расходов и лимитов. Не требуется для первого показа. |
| Подписки/платежи | Не реализовано | Нет тарифов, entitlement-проверок, webhook, платежей. Не требуется для первого показа. |
| PWA/offline/native | Не реализовано | Адаптивная вёрстка есть, но нет manifest/service worker, установки PWA, офлайн-синхронизации и Android/iOS. |
| Ошибки/контракт | Частично | DTO-валидация, HTTP-ошибки, часть машинных кодов, отдельные типизированные клиенты. Нет единого сгенерированного контракта и унифицированных кодов для всех ответов. |
| Технический долг | Остался | Общий PrismaModule не выделен; PrismaService повторяется в feature modules. Требуются CI, аудит proxy/rate limits, наблюдаемость и очистка истёкших сессий. |
| База/миграции | Подготовлено, живое состояние проверить | Миграции/backfill и legacy-owner есть в Git. Ранее пользователь проверил перенос 7 слов, 7 progress и 21 sessions на тестовой ветке; сегодняшние counts живой базы не читались. |

## Что изменилось относительно двух документов

1. Состояние «только схема Prisma» в дополнении устарело: уже есть рабочие модули
   авторизации, словаря, обучения, модерации и переводов, включая frontend.
2. Дополнение уточняет более раннее ТЗ: общая Word и связь UserWord вместо
   отдельных копий. Поэтому удаление из личного словаря означает отвязку; архив
   и пользовательские переопределения остаются отдельной задачей.
3. Email/password реализован собственным сервисом с bcrypt и сессиями. Supabase
   в базовом ТЗ был предложением, не поводом переписывать существующую авторизацию.
4. ТЗ описывает FSRS/четыре оценки; дополнение фиксирует двухкнопочный алгоритм
   прототипа. На показе честно называем его упрощённым интервальным повторением.
5. В дополнении упомянут ReadCommitted; текущая запись использует Serializable
   с повтором конфликтов, статистика — RepeatableRead. Возвращать старое значение
   только ради соответствия прежнему тексту не нужно.
6. Наличие колонок языка/провайдера/даты в схеме не означает готовый UI/OAuth/
   подтверждение email. «Языки переводов» и «перевод интерфейса» — разные функции.

## План до вторника

**P0 — публичный демо-контур:** два Render Web Service + существующая Neon
демо/тестовая ветка; согласованная миграция auth_sessions, если отсутствует;
отдельные USER/ADMIN; same-origin proxy; настоящие вход/refresh/logout/две учётки,
создание, модерация, перевод, тренировка и повторная загрузка прогресса.

**P0 — подготовка показа:** 8–12 проверенных слов разных артиклей/мн. числа,
два примера, два языка переводов; сценарий на 3–5 минут и один запасной скриншот
или локальный запуск. Не вводить личные пароли при показе, использовать демо-аккаунты.
За 5–10 минут открыть сервисы и пройти вход; Free может просыпаться около минуты.

**После показа:** полный UI ru/de/en/uk; история и профиль/часовой пояс/цель;
подтверждение email и восстановление; личные метаданные/архив; общий PrismaModule,
CI и backup/restore. Затем импорт/экспорт, расширенный SRS, глаголы/изображения,
ИИ/платежи/PWA. Порядок уточнять по обратной связи преподавателя и пользователей.

Не даём процент готовности: необязательные будущие модули делают его условным.
Точная формулировка: «реализовано ядро учебного прототипа; полный MVP по исходным
критериям приёмки и публичный запуск ещё не завершены».
