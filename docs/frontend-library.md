# Общая библиотека и язык перевода

- Вкладка «Библиотека» загружает опубликованные карточки через `GET /words?q=…` и принадлежность через `GET /words/mine`. Поиск отправляется кнопкой или Enter, до 100 символов. Старые запросы отменяются при поиске, смене языка и закрытии вкладки.
- «В мой словарь» вызывает только `POST /words/:id/dictionary`: карточка не копируется. Повторное добавление защищено серверной идемпотентностью. После успеха обновляются личный словарь и счётчик новых слов. Ошибку можно повторить вручную; автоматического повторения 5xx нет.
- Уже добавленные карточки отмечены «Уже в словаре». Убирать их можно в личном словаре: существующий DELETE удаляет только связь, прогресс и история остаются на сервере.
- Примеры доступны для чтения. Их переводы пока на русском, это обозначено отдельно.
- Список языков берётся из `GET /languages`. Выбор отправляет PATCH `/users/me/preferences` только с `translationLanguage`; язык интерфейса не меняется. Auth snapshot принимает только два языковых поля, сохраняя идентификатор и роль. Запоздалый ответ предыдущего аккаунта отклоняется, старый refresh не затирает сохранённый язык.
- После смены языка словарь, статистика и повторения перечитываются. Завершённые сохранённые результаты на экране очищаются, серверные сессии и SRS не изменяются. Во время тренировки, несохранённых результатов и текущих действий выбор недоступен; во время сохранения языка остальное содержимое временно `inert`. Черновик добавления/редактирования слова остаётся в состоянии формы.
- Карточки используют `selectedTranslation`; отсутствие нужного перевода не подменяется русским. Начальный перевод новой карточки по-прежнему вводится на русском. Полный перевод интерфейса — отдельный этап.

Редактор дополнительных переводов в личных карточках и модерации описан в `frontend-translations.md`.

Проверки: `npm run test:client`, `npm run lint`, `npm run build`.
Проверка настоящего API и Neon требует отдельно запущенного бэкенда и согласованного применения прежней auth-миграции. Тестовый mock не подтверждает работу реальной базы.
