# Общие книги и уроки — 12.11.2026

Карточка может иметь несколько общих источников: `bookSources?: { sourceBook:
string; lessonNumbers: number[] }[]`. Источники видны в словаре и библиотеке,
уроки перечислены рядом с конкретной книгой. Фильтр книги/урока использует
связанную пару: урок из другой книги не подходит выбранной книге.

Основные `sourceBook`/`lessonNumber` поддерживаются как совместимый fallback
для старого API. Названия из `personalBooks` остаются личными и не выводятся
как общие источники. Привязка только личной книги не получает чужие общие уроки.
Основной источник объединяется с импортированными без дублирования.

Backend migration уже применена к рабочей Neon с разрешения владельца.
Обновить backend на VPS вручную; новый frontend совместим с прежним ответом,
но дополнительные источники требуют обновлённого backend.

Контент: 2093 новые опубликованные карточки и источники 728 существующих;
после импорта 3734 карточки в словаре владельца. Пользовательские уроки
с названиями и редактор дополнительных общих источников — отдельные будущие задачи.
