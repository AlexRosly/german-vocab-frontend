# german-vocab-frontend

Frontend-репозиторий приложения для изучения немецких слов.

**[Roadmap: готовые функции, следующие этапы и критерии приёмки](docs/roadmap.md)**.

Хостинг frontend — Netlify по сообщению владельца; API размещён отдельно на VPS. [Инструкция Netlify](docs/netlify-deployment.md). Готовность кода и подтверждение последней версии на реальном хостинге учитываются раздельно.


## Требования
- Node.js 20.9+
- Запущенный backend из репозитория `german-vocab-backend`

## Запуск
```bash
cp .env.example .env.local
npm install
npm run dev
```
Откройте http://localhost:3000.

`NEXT_PUBLIC_API_URL` должен указывать на backend, по умолчанию `http://localhost:3001/api/v1`.

## Текущий объём — 09.11.2026

- Email/Google-вход, восстановление сессии и управление активными входами.
- Личный словарь и опубликованная библиотека; формы слов, мультиязычные переводы и примеры, книги, личные заметки/переводы, избранное и архив.
- Тренировки в двух направлениях и на артикли, персональное повторение, история, статистика и настройки цели/часового пояса.
- Модерация, связи слов, предложения исправлений с очередью администратора и ответом автору.
- Интерфейс RU/DE/EN/UK; независимый каталог 11 языков переводов.
- Массовое добавление опубликованных слов по книге/уроку/поиску с сохранением прогресса.
- Цвета der/das/die/множественного числа, озвучка и адаптивные элементы. Полная мобильная приёмка остаётся отдельной задачей.

Пользовательский Excel/CSV-импорт, восстановление пароля, PWA и другие незакрытые пункты описаны в roadmap. Старое описание «начального каркаса без авторизации и локализации» больше не отражает состояние проекта.
