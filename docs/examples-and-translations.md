# Примеры и переводы в форме слова

01.11.2026. Блок «Примеры употребления» находится в форме нового слова сразу
после заметок. Можно добавить/убрать до 20 строк. Полностью пустые строки
игнорируются, а перевод без немецкого предложения вызывает ошибку с сохранением
черновика. Один POST сохраняет слово вместе со всеми начальными примерами.

Переводы слова и примеров необязательны. Языки берутся из GET `/languages`.
Выбор языка редактирования независим от языка показа карточек. На каждом языке
свой черновик; переключение не теряет введённый текст. Черновик хранится только
до отправки/сброса формы, не сохраняется через перезагрузку страницы.
В редактировании пустой текст уже существующего языка отправляется как null
и удаляет только этот перевод. Остальные языки не стираются.

Существующие примеры остаются доступны для добавления и редактирования из
карточки, с тем же выбором языков и необязательным переводом. Немецкое предложение
обязательно. Словарь, библиотека и тренировка показывают selectedTranslation,
без русского fallback. В модерации отображаются все переводы примеров.
Переводы вводятся вручную; это не автоматический перевод и не локализация UI.

Основная форма редактирования слова также поддерживает независимые языки.
Отдельный редактор «Переводы» сохранён; его успешное сохранение обновляет
соответствующий язык открытой основной формы.

Проверки: test:client (52), lint и production build. Браузерная проверка выполнена
локально с временным mock API, а не с Neon: создание слова без русского перевода
с двумя примерами, один без перевода; переключение EN/UK с сохранением черновиков;
показ UK; удаление UK без потери EN; редактирование слова с EN/UK; перезагрузка
и показ выбранного языка в тренировке. Реальный smoke-тест нужен после Deploy.

Порядок выкладки: миграция `20261101160000_add_example_translations` в согласованной
демо-ветке, новый backend, затем этот frontend. На Render миграции не выполняются
автоматически. До обновления backend новую форму не выкладывать.

Миграция уже применена 01.11.2026 к подтверждённой демо-ветке «миграцион»;
проверена сохранность существующих данных и перенос русского перевода примера.
