# Уровень карточки может отсутствовать — R03, 14.11.2026

При редактировании карточки с level=null форма показывает «Без уровня» и сохраняет null. Выбор конкретного уровня сохраняется; его можно очистить через «Без уровня». Начальное значение A1 для создания новой карточки сохранено. Используется существующий перевод UI «Без уровня». Изменений API/БД и миграций нет.

Проверено: 158 клиентских тестов, lint и production build. В изолированном браузере проверена именно будущая версия коммита (HEAD + три правки), с синтетическим API: сохранение null, повторное открытие без подстановки A1, выбор B1 и повторное открытие с B1, очистка до null. Mock зарегистрировал PATCH-значения null → B1 → null. Рабочая БД не использовалась.

Dashboard содержит другие незакоммиченные изменения владельца. В индекс подготовлена версия HEAD только с тремя исправлениями уровня; остальные изменения dashboard и CSS сохранены в рабочем дереве. Выпуск требуется только во frontend Netlify.
