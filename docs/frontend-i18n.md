# Язык интерфейса ru/de/en/uk

01.11.2026. Переключатель вверху страницы меняет язык интерфейса независимо от
translationLanguage учебных карточек. Переведены вход/регистрация, словарь,
формы слова и примеров, библиотека, тренировка/результаты, прогресс, модерация,
редактор переводов, история тренировок, настройки обучения, активные входы, сообщения, подписи доступности и страница 404.

470 UI-сообщений находятся в `src/lib/i18n.ts`, с полными de/en/uk словарями и
русскими исходными ключами. Параметры сообщений подставляются как текст, без HTML.
Счётчики слов/карточек/дней используют Intl.PluralRules и Intl.NumberFormat;
даты — Intl.DateTimeFormat по языку UI, сохраняя исходные timestamps и часовой
пояс браузера. `html.lang`, title и description следуют текущему языку;
title/meta рендерятся средствами React 19, без конкурирующего статического title.

Авторизованный пользователь сохраняет interfaceLanguage через существующий
PATCH `/users/me/preferences`. Язык из профиля имеет приоритет при входе.
При новой регистрации выбранный язык страницы записывается в новый профиль.
До входа сохраняется только код языка в localStorage
`wortkarten-interface-language`; токен/роль/личные данные туда не записываются.
Если storage недоступно, настройка аккаунта продолжает работать. При неизвестном
коде используется ru. Вкладки гостей реагируют на storage event.

ApiClient сериализует два вида языковых PATCH, отправляя одно выбранное поле.
Ответ не может заменить identity, role или другой язык. Проверяются поколение
сессии, поддерживаемые языки и совпадение сохранённого поля с запросом.
Поздний ответ после смены аккаунта и устаревший refresh не откатывают настройку.
Ошибка сохраняет прежний язык и допускает повторную попытку.

Переключение UI не размонтирует WordDashboard и не перечитывает учебные карточки:
черновики, выбранная вкладка, тренировка и подтверждение модерации сохраняются.
Статусы enum, значения option и React keys остаются прежними; переводятся только
надписи. Названия языков показываются на самих языках. Немецкие слова, артикли,
примеры, заметки и введённые переводы отображаются без автоматического перевода.
Отсутствие выбранного перевода отображается на языке UI, без подстановки RU.

Известные сообщения API переводятся, неизвестные и технические ошибки получают
локализованное сообщение. Коды ошибок модерации и права остаются прежними.
Нативные сообщения проверки HTML-форм и элементы браузера зависят от браузера.

Проверки: 90 client-тестов, lint, production build. Тесты покрывают полноту
словарей/параметров, UI-строки и неизменность технических идентификаторов,
счётчики, даты, ошибки, сохранность учебного текста, две языковые настройки,
параллельные записи, ошибки ответов, смену аккаунта и refresh.

Браузерная проверка выполнена на localhost с временным mock API и искусственными
аккаунтами: все четыре языка, неверный пароль, guest reload, профиль при входе,
новая регистрация, черновик при смене языка, переключение во время тренировки,
500 при записи языка с успешным повтором, сохранение сессии и даты прогресса,
библиотека, редактор переводов, модерация/публикация/фильтры, 404 и заголовок.
Это не проверка публичного Render или настоящего Neon.

Backend, Prisma и база для этого этапа не меняются. Выкладка: Manual Deploy
последнего frontend main на Render; затем проверить переключение UI, reload,
независимость языка карточек и основные сценарии на настоящем API.
