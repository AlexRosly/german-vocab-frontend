# Редактирование переводов карточек

Кнопка «Переводы» в личной карточке видна автору PENDING_REVIEW/REJECTED
и администратору. В модерации ADMIN может открыть тот же редактор для любой
просматриваемой карточки, не добавляя её в личный словарь. Сервер проверяет доступ
при каждом GET/PUT; frontend не назначает роли и не обходит права публикации.

- Каталог языков берётся из GET `/languages`. Выбор языка в окне меняет только
  редактируемый перевод, не настройку показа учебных карточек пользователя.
- GET `/words/:id/translations/:language` возвращает точный перевод, включая null.
  Русский текст не используется как подстановка для отсутствующего перевода.
- PUT по тому же пути отправляет только `{text}`: NFC, trim, от 1 до 1000 Unicode
  символов. Запись обновляет одну языковую строку общей карточки; другие языки,
  личные связи, учебные сессии и интервалы не переписываются.
- Сервер синхронизирует русский перевод с основным полем слова. Если эта карточка
  уже открыта в основной форме редактирования, её русский текст обновится также:
  последующий PATCH формы не вернёт старый перевод.
- Сохранение перевода REJECTED возвращает карточку на проверку. В модерации
  перечитываются очередь и детали с новой revision; старое подтверждение решения
  сбрасывается, автоматического одобрения после редактирования нет.
- Окно использует native dialog: фон недоступен для взаимодействия, Escape
  и закрытие заблокированы во время записи. Во время тренировки и несохранённых
  результатов редактор не открывается. Несохранённый текст удерживает выбранный
  язык; есть явная отмена изменений или закрытие без сохранения.
- Ошибки чтения можно повторить, ошибки сохранения оставляют черновик. При
  неоднозначном ответе можно явно перечитать перевод с отменой черновика.
  На 403/404 запись блокируется до закрытия. Автоповторов 5xx нет; стандартный
  authenticated retry после refresh выполняет общий apiClient.
- Уход со страницы отменяет чтения; поздний результат записи после размонтирования
  не обновляет другой аккаунт. Пустое значение не используется для удаления перевода.

Проверки: `npm run test:client`, `npm run lint`, `npm run build`, браузерные сценарии.
Начальный перевод новой карточки пока вводится на русском. Переводы примеров
и полный перевод интерфейса остаются отдельными этапами.
