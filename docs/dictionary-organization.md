# Избранное и архив личного словаря

Реализовано 03.11.2026. Флаги isFavorite/isArchived находятся в UserWord и относятся только к владельцу. Новые и прежние записи по умолчанию активны и не избраны. Общие Word, публикация, переводы, примеры и связи не изменяются.

## Поведение

В словаре есть разделы «Активные слова» (по умолчанию), «Избранное», «Архив», «Все слова». Поиск, уровень, урок и остальные фильтры работают вместе с выбранным разделом. Избранное показывает активные избранные карточки; отметка сохраняется в архиве и возвращается при восстановлении. Обычная тренировка использует выбранные фильтры, исключая архив даже в разделе «Все слова». На странице одного архива эта тренировка недоступна. Подборки новых слов и повторения используют весь активный словарь независимо от локальных фильтров.

Архив сохраняет UserWord, личные переводы, заметки, прогресс и расписание. Восстановление не обнуляет обучение и может сразу вернуть слово в повторение, если срок прошёл. Личные материалы доступны и в архиве. Повторное добавление уже архивной карточки через библиотеку не снимает архив автоматически. «Убрать из словаря» остаётся отдельным действием: удаляет UserWord; при новом добавлении флаги начинаются с defaults, история/прогресс и отдельно хранимые личные материалы сохраняются.

Новые слова, повторение и текущие показатели прогресса исключают архивные карточки. Общий счётчик словаря включает архив. История и число сохранённых тренировок сохраняются. Уже начатую на другом устройстве тренировку можно завершить после архивирования: сохранение ответов требует собственную читаемую карточку, но не требует, чтобы она всё ещё была активна. Это не выдаёт архивные карточки в новую серверную очередь. Интервалы SRS 1/3/7/14/30 не изменены.

## API и конкуренция

GET/PUT `/api/v1/words/:id/dictionary-settings`, AuthGuard, Cache-Control: no-store. Нужны собственная UserWord и видимость опубликованной либо своей карточки; ADMIN не получает обхода этого условия. GET возвращает `{ wordId, isFavorite, isArchived, revision }`. PUT принимает revision и хотя бы один булев флаг; строки, null, userId/role и прочие поля отклоняются. Строгое условное обновление одной UserWord в serializable-транзакции, при stale revision — 409. Операция не создаёт новую связь и не меняет общие карточки. Повторной записи на 5xx нет; после неопределённого результата frontend блокирует новые изменения и запуск обучения до успешного явного обновления словаря. Ошибка и кнопка перечитывания показаны у соответствующей карточки.

`/words/mine` возвращает собственный объект dictionaryEntry без wordId: `{ isFavorite, isArchived, revision }`. Исходные массивы userWords и чужие флаги не выдаются. Общая библиотека и обычный просмотр Word этого поля не содержат. Все карточки и примеры остаются одним запросом списка, без GET настроек для каждой карточки.

Миграция 20261103140000_add_dictionary_organization добавляет два boolean с defaults false, revision с DB-default gen_random_uuid()::text и индекс userId/isArchived. DB-default сохраняет совместимость вставок старого backend во время выкладки. В демо-ветке «миграцион» миграция уже применена: прежние колонки UserWord и все проверенные остальные таблицы сохранили количества и контрольные суммы. Для других баз нужен prisma migrate deploy до запуска нового backend. Порядок выкладки: backend → frontend. Публичная работа новой версии пока не подтверждена.

## Проверки

Backend: words 66, study 57, languages 39, moderation 38, auth 28; build. Frontend: 117 client-тестов, lint/build. Браузер с mock API: добавление/снятие избранного, архив, восстановление с сохранением отметки, отсутствие архивного слова в обычной тренировке и счётчике новых слов, ошибка 500 без автоматического повтора и ручное перечитывание у карточки, два аккаунта, desktop и 390×844. Настоящий Safari/iPhone отдельно не проверялся. Мобильная компоновка доработана только для карточек личного словаря; общий аудит адаптивности остаётся в плане.

На настоящем PostgreSQL проверены собственные флаги, DB-default revision, stale revision, исключение архива из новых/просроченных слов и восстановление без изменения общего Word или прогресса. Тест выполнен внутри полностью откатанной транзакции; временных записей не осталось. Это не проверка параллельных PostgreSQL-транзакций.
