# Кликабельные связанные слова

Раздел «Связанные слова» доступен в личном словаре, библиотеке и карточке модерации. Загрузка выполняется при раскрытии. Нажатие открывает диалог с карточкой, выбранным переводом, примерами и её связями. Можно переходить дальше и вернуться назад; Escape и «Закрыть» закрывают диалог. Просмотр не меняет личный словарь или прогресс.

Содержимое загружается через существующий apiClient. Ошибку можно повторить; запросы при смене карточки/языка отменяются, отсутствующие переводы не подменяются русским. Тексты интерфейса переведены на ru/de/en/uk. Права на просмотр определяет backend.

Требуется backend с миграцией 20261102120000_add_word_relations. Администратор управляет связями в модерации через «Редактировать связи»: поиск по слову/переводам, добавление и удаление одной двусторонней связи. Подробнее — [frontend-moderation.md](frontend-moderation.md).

03.11.2026 в демо-ветке «миграцион» группа der Lohn, das Gehalt, die Bezahlung, die Vergütung дополнена до всех шести пар. Добавлено пять отсутствовавших связей; тексты, timestamps и статусы карточек сохранены. Это связанные по теме слова с различиями в употреблении. Другие группы автоматически не достраиваются.
